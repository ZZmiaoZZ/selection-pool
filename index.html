纳入与排除标准

由生成脚本强制执行，不靠人工记忆

必须保留的字段

  • 品牌中文名 + 品牌英文名
  • 型号（英文，海外页面实际在用的写法）
  • 拆机/替换升级件（可搜核心件 + 高价值非耗材替换/升级件）
  • 状态（未处理 / 掌握了 / 不做 / 待定）
  • 备注（自由文本，本机保存）

明确排除的方向

  • 耗材（滤芯、滤网、刀片、喷嘴、打印材料等）
  • 电池与电芯
  • 电源适配器、充电器、线缆
  • 低价抛货（按各站低价区间剔除，不进入主池）
  • 纯装饰件（贴纸、外观壳、灯效等无功能件）

中国品牌标识

  • 品牌来源含「中国」的记录，中英文品牌名均以红色加粗显示
  • 单元格附左侧红色标线与「中国」角标
  • 各池工具栏可按品牌来源直接筛选

数据流转与重新生成

改数据或改结构都要动脚本，不要只改最终 HTML
  1. build_selection_pool.ps1：读取旧版美国站网页提取基础记录，做品牌中英文归一、拆机件补全、排除规则过滤、优先级排序与连续重编号，输出AMZ美国站选品池单页（原主池与优先池已合并，工具栏「优先级」可筛 P1/P2/P3）。
  2. build_mexico_pool.ps1：内置 Mercado Libre México 记录，按 18 MXN = 1 USD 工作汇率折算并过滤低价抛货，输出MC墨西哥选品池。
  3. build_poland_pool.ps1：内置 Allegro.pl 记录，使用 PLN 价格与近期购买信号，输出AL波兰站选品池。
  4. build_japan_pool.ps1：内置 Amazon.co.jp 记录，使用 JPY 价格与日语搜索词，按 1 RMB ≈ 20.8 JPY 工作换算并过滤低价抛货，输出AMZ日本站选品池。
  5. enhance_final_pools.ps1：把 assets\pool-ui.css 与 assets\pool-ui.js 内联注入五个页面的 <!--FINAL-UI-ASSETS--> 锚点，并按真实数据重新生成本页。

完整重建顺序：先跑四个 build_*.ps1，再跑 enhance_final_pools.ps1。共享样式与交互只改 assets\ 下的两个文件，改完重跑装配脚本即可同步到全部页面。
